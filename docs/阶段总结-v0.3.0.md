## 1. 本阶段目标

V2 阶段在 v0.2.0 基线上完成四块能力 + 面板增强 + 测试发布：

1. **多群**：一个 dsh 会话支持多个互相隔离的群
2. **消息编辑/撤回**：管理员可修改或撤回已发消息
3. **AI 主动发言 + AI 互 @**：轮末 AI 可补充，AI 之间可 @（受限、防循环）
4. **首轮中断摘要**：首轮被中断时为后续轮次提供上下文
5. **面板增强**：群重命名、只读工具活动提示、成员 token 用量
6. **测试与发布**：v0.3.0、文档同步、真实环境验证

## 4. 关键设计决策

| 决策 | 结论 | 理由 |
|---|---|---|
| maxGroups 默认值 | **1**（测试期临时改 2 便于验证） | 与 v0.2 行为完全一致，多群能力存在但需配置放开 |
| 多群持久化 | `<sessionId>-<groupId>.jsonl`，group-1 复用 v1 文件名 | v1 日志零手工迁移，文件名即兼容 |
| 群级 vs 全局配置 | 面板改群级配置；create 上限用启动默认值 | 实现简单；文档已注明差异 |
| AI 主动发言 | 默认关闭 + 每轮上限 | 防低质量插话，逐条可撤回 |
| AI 互 @ 防循环 | 深度上限 + `${round}:${targetId}` 去重 | 一轮内同目标不重复触发 |
| 成员 usage 口径 | 与 dsh 主对话框一致（input 未缓存 / cacheRead 单独计） | 同源数据，缓存命中率 = cacheRead/(input+cacheRead) |

## 6. 遗留问题与注意事项

| 项 | 说明 |
|---|---|
| maxGroups 默认值 | **定稿 1**（v0.4.0-②）；面板可调大，且面板设置已对 create 生效（v0.4.0-①） |
| 面板改 maxGroups 与 create 上限 | 面板改的是群级配置，create 上限用启动默认值——若需面板生效需重构（service 级 per-session 覆盖） |

| AI 审查目录问题 | 群聊 AI 的 cwd 继承自会话，可能读到非 v2 目录导致误判；人工核实代码时须确认目录 |
| 已污染的旧摘要 | 修复前产生的脏摘要留在历史 jsonl；验证/演示用新话题或新群 |
| 旧群聊数据 | 备份于 `/home/sll/projects/chatgroup-旧日志备份/` |
