## 2. 已确认决策补充

### D-增量 1：持久化策略

- 不使用 dsh session 事件；
- 不修改 deepseek-harness 源码；
- 使用项目目录：

```text
<项目 cwd>/.dsh/chatgroup/<sessionId>.jsonl
```

- `state` 记录 = 全量快照；
- `message` 记录 = 增量消息；
- 重启后恢复；解散删除；旧数据按 `topic-1` 兼容。

### D-增量 2：滑动窗口

- 默认 `maxPromptMessages = 40`；
- `0` 表示不限制；
- **当前议题锚点始终保留**，不参与窗口截断；
- 早期测试曾临时改为 10，验证后恢复 40。

### D-增量 3：自动多轮讨论

- 默认 3 轮，最大 10 轮；
- 支持群聊中途启动；
- 用户插话不重置轮次；
- 首轮盲发规则不变；
- `/group stop` 同时终止自动模式；
- 重启不自动续跑，恢复时写入终止系统消息。

### D-增量 4：新议题

- 命令：`/group topic <议题内容>`；
- 新议题轮次重置为 1，并重新盲发；
- 旧话题只显示在 UI 历史中；
- 旧话题不进入新议题 AI 的 prompt；
- 消息按 `topicId` 隔离；
- V1 不支持切回旧话题继续讨论。

### D-增量 5：临时写权限

- 仅 `@` solo 发言支持；
- 语法：`/group at <AI> --write <内容>`；
- UI：@ 目标选中后显示“允许本次写入”复选框；
- `read-only` 沙箱下复选框灰色禁用；
- 服务端 read-only 下直接阻止并提示；
- 白名单 = 只读工具 + `write/edit`，不放 bash/terminal/subagent；
- 权限仅当次发言有效，自动重试沿用；
- 明确限制：工具级授权，不限制具体文件路径。

## 3. 数据模型增量

```ts
interface ChatTopic {
  id: string
  title: string
  round: number
  messageCount: number
  createdAt: number
}

interface SoloRequest {
  memberId: string
  writeAccess: boolean
}

interface ChatGroupMessage {
  topicId?: string        // 旧消息缺省，归入 topic-1
  writeAccess?: boolean   // 仅临时写权限发言为 true
}

interface ChatGroupSnapshot {
  totalMessages: number
  hasMoreMessages: boolean
  oldestLoadedSeq?: number
  currentTopicId: string
  topics: ChatTopic[]
  sandboxMode?: string
  config: ChatGroupConfig
  soloQueue: SoloRequest[]
}
```

## 4. 配置项增量

全局/群级配置：

| 配置 | 默认 | 说明 |
|---|---|---|
| maxAi | 5 | 群 AI 成员上限，群级可编辑 |
| defaultTimeoutMs | 300000 | 新成员默认发言超时，群级可编辑 |
| readonlyTools | read, read_image, glob, grep | 群级可编辑 |
| waitTimeoutMs | 25000 | RPC wait 上限，群级可编辑 |
| maxPromptMessages | 40 | prompt 滑动窗口，0 = 不限 |
| messagePageSize | 100 | RPC 快照尾页大小 |

注意：面板修改的是**当前群**配置；profile patch 只决定新群默认值。

## 5. RPC 增量

| Endpoint | 说明 |
|---|---|
| `messages.before` | 向前分页 |
| `topic.messages` | 获取指定话题完整消息 |
| `topic.start` | 开启新议题 |
| `auto.start` | 启动自动多轮讨论 |
| `settings.config.update` | 更新当前群配置 |
| `export` | 导出完整 Markdown |
| `config.get` | 全局默认配置 |

原有 `snapshot / wait / create / dissolve / send / at / stop / members.* / settings.update / catalog` 保持可用。

## 6. 命令增量

```text
/group auto <轮数 1-10> [议题]
/group topic <议题内容>
/group at <AI名称> [--write] <内容>
/group config
```

---

## 7. 兼容性

- 旧 JSONL 无 `topicId` 的消息：恢复时归入 `topic-1`；
- 旧 JSONL 无 `currentTopicId / topics / config`：恢复时使用默认值和历史话题；
- 旧 snapshot 无 `sandboxMode`：按 `read-only` 保守处理；
- 旧群无 `writeAccess`：按 false 处理。
