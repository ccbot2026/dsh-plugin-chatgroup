## 2. 详细说明

### V2I-01 首轮中断摘要串话题（缺陷修复）

**现象**：新话题（topic-2）首轮被用户中断时，系统摘要里混入上个话题（topic-1）的 round-1 发言，甚至出现当前群不存在的历史成员名（如早期测试的 ds-a/ds-b）。

**根因**：`appendFirstRoundInterruptSummary` 过滤条件只有
`round === 1 && status === 'completed' && 非 user/system && text 非空`，
**缺少 topicId 限定**，把本群所有历史话题的 round-1 发言全部拼进摘要。

**修复**（`src/group-service.ts`）：

```ts
&& (message.topicId === undefined ? 'topic-1' : message.topicId) === group.currentTopicId
```

**验证**：新增跨话题回归测试；真实环境重测通过（用户确认"摘要正常了"）。

**注意**：已污染的旧摘要消息仍留在历史 jsonl 中，验证/演示时应开新话题或新群，避免旧数据干扰。

### V2I-02 AI 消息 mentionIds 回填

**现象**：AI 消息正文写了 `@成员名` 且确实触发了追加回应，但消息元数据 `mentionIds` 恒为 `[]`，无法用于 @ 统计或 UI 高亮。

**修复**：`resolveAiMentions` 文本匹配成功后，把被 @ 成员 id 回填到该消息的 `mentionIds` 并持久化。

**决策**：回填语义 = "正文含 @ 且匹配到群内 AI 成员" 即回填；被深度拦截的 @ 也回填（拦截仅阻止入队回应，不改变消息内容）。

### V2I-03 配置面板重新组织

**反馈**（用户测试）：群名称、新议题、自动多轮、群配置、成员管理、@ 开关全部混在一个侧栏；配置输入框有值时 placeholder 不显示、且 placeholder 用英文 key 无中文说明。

**重构**：

- 侧栏改为 4 个可折叠分区（`<details>`）：**群信息 / 讨论控制 / 群配置 / 成员管理**
- 每个配置项两行：中文名称 + 当前值 + 说明（如 `AI 成员上限 当前 2 · 1-5`）+ 输入框
- 11 项配置全部有中文标签（maxAi / maxGroups / defaultTimeoutMs / readonlyTools / waitTimeoutMs / maxPromptMessages / messagePageSize / maxEditableMessages / aiProactive / maxProactivePerRound / maxAiMentionDepth）

### V2I-04 成员 token 用量显示

**需求**（用户测试后提出）：类似主对话框底部的统计，为每个 AI 成员显示 token 用量，至少含输入/输出 token 与缓存命中率。

**实现**：

- `ai-speaker.ts` 新增 `onUsage` 回调：监听子 Agent 会话 `assistant/chunk`（`type:'usage'`）与 `assistant/message` 的 `usage` 字段，收集 `TokenUsage`
- `ChatGroupMessage.usage`：每条 AI 消息记录本次发言用量
- `ChatGroupSnapshot.memberUsage`：按成员累计整个会话用量
- 面板成员列表显示 `输入 X · 输出 Y · 缓存 Z%`（≥1000 自动格式化为 `1.6K`）

**口径**：与 dsh 主对话框一致——`inputTokens` 为未缓存输入，缓存命中单独计 `cacheReadTokens`，缓存命中率 = `cacheRead / (input + cacheRead)`。

### V2I-05 maxGroups 面板可配

原实现 `maxGroups` 只有默认常量（`DEFAULT_MAX_GROUPS`），面板无输入框。补配置表单字段与保存逻辑。注意：create 群数上限校验用的是**启动时默认值**（service 级），面板改群级 `maxGroups` 只影响展示；测试期将默认值改为 2 便于多群验证。

### V2I-06/07/08 测试补强

- 跨话题摘要回归：断言「topic-1 的 round-1 发言不得进入 topic-2 摘要」
- mentionIds 回填断言：互 @ 后消息 `mentionIds` 含目标成员 id
- usage 收集用例：模拟子会话 usage 事件 → 消息 `usage` + `memberUsage` 聚合
