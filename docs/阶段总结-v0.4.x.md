## 4. 关键设计决策

| 决策 | 结论 | 理由 |
|---|---|---|
| maxGroups 默认值 | **1** | 与 v0.2 行为一致，多群能力按需放开（面板可调） |
| maxGroups 生效层级 | per-session 覆盖 | 面板改的是群级配置，create 上限需会话级；覆盖在 updateConfig 时同步 |
| 浏览器 E2E | Host 层 RPC 集成替代 | 当前环境无 playwright/浏览器；真实浏览器用例留待有环境时补 |
| usage 增量 | 消息追加时只重算该成员 | 避免长会话每次流式 delta 全量扫描 |
| 设置面板折叠 | header 折叠图标 + 外部点击关闭 | 与主对话框交互一致；原"关闭"按钮冗余移除 |
| 输入框聚焦 | 外层胶囊边框高亮（圆角统一） | 内层 textarea 直角高亮与外框不协调 |
