## 1. 项目概述

`dsh-plugin-chatgroup` 是 DeepSeek Harness（dsh）的群聊插件，用于让 **1 个人类用户与最多 5 个 AI 成员**在同一个讨论群中按规则发言，减少在多个 AI 聊天窗口间切换和人工转发消息的成本。

- TypeScript 开发
- dsh 插件形态：Host 半 + Web Client 半
- 不修改 deepseek-harness 源码
- 不写自定义 session 事件

## 4. 技术架构

```text
dsh Web UI
  └─ ChatGroupPanel（shell.overlay 抽屉）
       │  /chatgroup RPC + wait 长轮询
Host
  └─ ChatGroupService（Map<sessionId, InternalGroup>）
       ├─ RoundScheduler：轮次 / @ / auto / topic / write
       ├─ VisibilityFilter：盲发 / 滑动窗口 / 议题锚点
       ├─ AiSpeaker：ctx.subagents.start('spawn') one-shot
       └─ Persistence：项目 .dsh/chatgroup/*.jsonl
```

### 关键设计

- 每次 AI 发言 = 一个 `spawn` one-shot 子 Agent
- 默认工具白名单：`read / read_image / glob / grep`
- 临时写权限白名单：只读工具 + `write / edit`
- 子 Agent 审批固定 `never`，沙箱继承父会话
- 群状态按 sessionId 隔离；消息按 topicId 隔离
- JSONL 记录 `state`（全量快照）与 `message`（增量消息）
- 旧数据兼容：无 topicId 的消息归入 `topic-1`

## 5. 持久化

文件：

```text
<项目目录>/.dsh/chatgroup/<sessionId>.jsonl
```

行为：

- 建群/成员/配置/轮次变化写 `state` 记录
- 每条消息写 `message` 记录
- dsh 重启后自动恢复
- 解散群删除日志
- 正在发言时重启：`speaking` 消息恢复为 `cancelled`
- 自动讨论中断：写入系统终止消息

## 8. 已知限制

1. 一个会话仅支持一个群。
2. 写权限是工具级，不限制具体文件路径。
3. 群配置保存仅 idle 时生效。
4. 消息编辑/删除、附件、图片暂不支持。
5. 不跨会话共享群。
6. 群成员不保留跨轮私有记忆；每轮 one-shot。
7. prompt 滑动窗口默认 40 条，议题锚点始终保留。
8. 浏览器 E2E 自动化暂缓。

## 9. 安装与使用

```sh
# 推荐：安装到内置 web profile
dsh plugin --profile web add /path/to/dsh-plugin-chatgroup
dsh web --port 3081
```

```sh
# 自定义 profile
dsh plugin --profile dsh-chatgroup add /path/to/dsh-plugin-chatgroup
# package.json 的 dsh.profile.bundles 需包含：
# @deepseek-ai/dsh-base
# dsh-plugin-chatgroup
# @deepseek-ai/dsh-web-app
# 注意：web-app 只加 bundles，不要 npm 安装
dsh --profile dsh-chatgroup --port 3081
```
